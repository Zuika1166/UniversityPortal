# University Portal

Учебный проект для работы с данными университета. На сайте можно посмотреть студентов, преподавателей и учебные курсы. Информация загружается из University API.

В разделе студентов есть поиск, фильтры и сортировка. Можно открыть карточку студента, добавить новую запись, изменить её или удалить. Редактировать и удалять можно только студентов своей команды.

Преподавателей и курсы можно просматривать, искать нужные записи и открывать подробную информацию.

Сервер написан на Java с использованием Spring Boot. Интерфейс сделан на HTML, CSS и JavaScript.

## Как запустить

Для запуска нужны Java 21 и Maven.

Скачайте проект и откройте терминал в его папке:

```powershell
git clone https://github.com/Zuika1166/UniversityPortal.git
cd UniversityPortal
mvn spring-boot:run
```

После запуска сайт будет доступен по адресу http://localhost:8080.

Если порт 8080 занят, перед запуском можно указать другой:

```powershell
$env:SERVER_PORT = "8081"
mvn spring-boot:run
```

В этом случае сайт откроется по адресу http://localhost:8081.

## API-ключ

Для раздела курсов нужен ключ University API. Его можно получить через https://api-university.vercel.app/ или уточнить у преподавателя.

В PowerShell перед запуском сервера задайте ключ:

```powershell
$env:UNIVERSITY_API_KEY = "ваш_ключ"
mvn spring-boot:run
```

Ключ не нужно добавлять в файлы проекта или загружать на GitHub.

Без ключа студенты и преподаватели доступны, если внешний API работает.

## Проверка

Чтобы запустить тесты, выполните в папке проекта:

```powershell
mvn test
```

Тесты работают с локальным тестовым сервером и не изменяют данные настоящего University API.
