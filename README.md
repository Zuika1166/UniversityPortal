# University Portal

Информационный веб-портал для учебного отдела университета. Приложение объединяет данные студентов, преподавателей и учебных курсов из University API в одном интерфейсе и предоставляет безопасный серверный шлюз к внешнему сервису.

## Назначение

Система предназначена для сотрудника учебного отдела, которому нужно находить студентов, видеть их успеваемость и статус, просматривать преподавателей, курсы и преподавателей, ведущих курсы, а также создавать и обслуживать тестовые студенческие записи команды.

В первой версии предусмотрена одна пользовательская роль. Регистрация и вход не требуются.

\`\`\`text
Браузер
   |
   v
University Portal (Java + Spring Boot)
   |
   +-- Статический frontend
   |
   +-- REST-контроллер /api/portal
            |
            +-- Валидация и правила доступа
            |

                        |

                                    |

Браузер никогда не обращается к University API напрямую. API-ключ курсов добавляется только сервером в заголовок \`X-API-Key\` и не передаётся в HTML, JavaScript или ответы нашего API.

Техническое задание исходно описывает Node.js-сервер. В этой реализации серверная часть перенесена на Java/Spring Boot, при этом пользовательские сценарии и контракт обмена сохранены.

## Основные возможности

### Главная страница

- Статистика студентов, преподавателей и курсов
- Независимая загрузка карточек: сбой одного источника не блокирует остальные
- Быстрые переходы в соответствующие разделы

### Студенты

- Таблица с номером, именем, почтой, курсом, средним баллом и статусом
- Поиск по имени, фамилии и почте через внешний поисковый маршрут
- Фильтр по курсу или статусу
- Сортировка по поддерживаемым полям
- Пагинация
- Карточка со всеми полями
- Создание, частичное редактирование и удаление тестовых записей команды
- Валидация на стороне браузера и Java-сервера
- Подтверждение удаления

### Преподаватели

- Список с табельным номером, именем, кафедрой, должностью, кабинетом и почтой
- Сортировка и пагинация
- Подробная карточка преподавателя

### Курсы

- Список с названием, кодом, кредитами, семестром, статусом и преподавателем
- Поиск, сортировка и пагинация
- Подробная карточка с описанием, вместимостью и зачислением
- Разрешение \`teacherId\` в имя преподавателя
- Контролируемое сообщение об ошибке, если преподаватель недоступен

## Интерфейс

Для всех разделов реализованы состояния загрузки, успешного ответа, пустой выдачи, ошибки и повторного запроса. При сохранении кнопка блокируется до завершения запроса. После успешных изменений данные перезагружаются. Интерфейс адаптирован под небольшие экраны.

## Взаимодействие с API

### Локальные маршруты

| Метод | Маршрут | Назначение |
| --- | --- | --- |
| GET | / | Интерфейс |
| GET | /api/portal/health | Проверка сервера |
| GET | /api/portal/students | Список, поиск, фильтры, сортировка |
| GET | /api/portal/students/{id} | Карточка студента |
| POST | /api/portal/students | Создание студента |
| PATCH | /api/portal/students/{id} | Частичное изменение |
| DELETE | /api/portal/students/{id} | Удаление студента |
| GET | /api/portal/teachers | Список преподавателей |
| GET | /api/portal/teachers/{id} | Преподаватель |
| GET | /api/portal/courses | Список и поиск курсов |
| GET | /api/portal/courses/{id} | Курс и преподаватель |

Для списков доступны параметры \`page\`, \`limit\`, \`sortBy\` и \`sortOrder\` (\`asc\`/\`desc\`). Дополнительные параметры: \`q\` для поиска студентов и курсов, \`year\` и \`status\` для фильтрации студентов. Одновременно можно использовать поиск либо один фильтр, поскольку внешний API предоставляет отдельные маршруты для этих операций.

### Нормализация ответов

Список:

\`\`\`json
{
  "items": [],
  "pagination": {
    "page": 1,
    "limit": 10,
    "total": 0,
    "totalPages": 0
  }
}
\`\`\`

Карточка:

\`\`\`json
{
  "item": {
    "id": 1
  }
}
\`\`\`

Ошибка:

\`\`\`json
{
  "error": {
    "code": "NOT_FOUND",
    "message": "Запись не найдена"
  }
}
\`\`\`

Сервер различает ошибки валидации (\`400\`), авторизации внешнего API (\`401\`), чужие тестовые записи (\`403\`), отсутствие ресурса (\`404\`), конфликт (\`409\`), недоступность внешнего сервиса (\`502/503\`) и тайм-аут (\`504\`). Ответы не содержат сырых исключений внешнего сервиса.

## Защита общих данных

При создании студента сервер сам присваивает номер в формате \`TEAM-01-<timestamp>\`. Префикс меняется через переменную \`TEAM_ID\`. Поле \`studentNumber\` нельзя подменить в запросе на создание или изменение.

Редактирование и удаление разрешено только для студентов с номером, начинающимся с префикса своей команды и содержащим числовой суффикс. Перед операцией сервер повторно читает карточку студента. Записи других команд не изменяются.

Без авторизации и отдельного реестра владельцев такое разграничение основано на номере команды, а не на подтверждённой личности создателя. Это ограничение первой версии проекта.

## Запуск локально

Необходимы JDK 21 и Maven 3.9+.

\`\`\`bash
git clone https://github.com/Zuika1166/UniversityPortal.git
cd UniversityPortal
mvn spring-boot:run
\`\`\`

Откройте \`http://localhost:8080\`. Без API-ключа раздел курсов покажет сообщение о необходимости настройки ключа; остальные разделы продолжат работать при доступности внешнего сервиса.

### Переменные окружения

Скопируйте \`.env.example\` в \`.env\` и заполните значения. Файл \`.env\` не коммитится.

| Переменная | Значение по умолчанию | Назначение |
| --- | --- | --- |
| UNIVERSITY_API_URL | https://api-university.vercel.app | Адрес внешнего API |
| UNIVERSITY_API_KEY | пустое | Ключ для маршрутов курсов |
| TEAM_ID | 01 | Префикс тестовых записей |
| UPSTREAM_TIMEOUT_SECONDS | 8 | Тайм-аут внешнего API |
| SERVER_PORT | 8080 | Порт портала |

Spring Boot получает значения из переменных окружения процесса. Сам по себе файл \`.env\` не подгружается при запуске через Maven.

На Linux/macOS:

\`\`\`bash
set -a
. ./.env
set +a
mvn spring-boot:run
\`\`\`

В PowerShell переменные можно задать так:

\`\`\`powershell
$env:UNIVERSITY_API_KEY = "your-key"
$env:TEAM_ID = "01"
mvn spring-boot:run
\`\`\`

Актуальные внешние маршруты и получение ключа: https://api-university.vercel.app/

## Docker

\`\`\`bash
docker build -t university-portal .
docker run --rm -p 8080:8080 --env-file .env university-portal
\`\`\`

Ключ задаётся в файле окружения на вашей машине, а не помещается в образ.

## Тесты

\`\`\`bash
mvn test
\`\`\`

Интеграционные тесты запускают управляемый локальный HTTP-сервер вместо внешнего University API. Они проверяют маршруты, нормализацию, пагинацию, создание, PATCH, DELETE, разграничение чужих записей, передачу API-ключа, объединение курса с преподавателем, кодирование поиска и ошибки 401/404/500.

Тесты не меняют общие данные University API.

## Ограничения и дальнейшие улучшения

- Первая версия без авторизации сотрудников и без собственной БД
- Источник данных — внешний сервис, поэтому его простои влияют на интерфейс
- Для объединения курсов с преподавателями могут понадобиться дополнительные HTTP-запросы
- Для полноценной безопасности командной работы необходимы аутентификация и серверный реестр авторства
- Учебные сценарии не должны изменять исходные записи других команд
